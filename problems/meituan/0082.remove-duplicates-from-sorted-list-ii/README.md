# 82. 删除排序链表中的重复元素 II  [Medium]

> https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/

给定一个 **已排序** 的链表的头节点 head。

删除原始链表中所有 **重复** 数字的节点，只留下 **不同** 的数字。

返回 **已排序** 的链表。

 

**示例 1：**

```

**输入：**head = [1,2,3,3,4,4,5]
**输出：**[1,2,5]

```

**示例 2：**

```

**输入：**head = [1,1,1,2,3]
**输出：**[2,3]

```

 

**提示：**

	- 链表中节点数目在范围 [0, 300] 内

	- -100 <= Node.val <= 100

	- 题目数据保证链表已经按升序 **排列**
