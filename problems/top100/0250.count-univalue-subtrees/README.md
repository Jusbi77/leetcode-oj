# 250. 统计同值子树  [Medium]

> https://leetcode.cn/problems/count-univalue-subtrees/

给定一个二叉树，统计该二叉树数值相同的 子树 个数。

同值子树是指该子树的所有节点都拥有相同的数值。

 

示例 1：**

```

**输入：**root = [5,1,5,5,5,null,5]
**输出：**4

```

示例 2：**

```

**输入：**root = []
**输出：**0

```

示例 3：**

```

**输入：**root = [5,5,5,5,5,null,5]
**输出：**6

```

 

**提示：**

	- 树中节点的编号在 [0, 1000] 范围内

	- -1000 <= Node.val <= 1000
